## 👨‍💻 About Me

I am a **Computer Science graduate** with a strong foundation in **software engineering, backend development, and AI engineering**, with hands-on experience building real-world applications using Python and modern technologies.

Currently working as a **Software Engineer Intern at Axiom World**, I contribute to the development and maintenance of Python-based enterprise applications while building practical experience in software architecture, ERP development, AI-driven automation, scalable system design, debugging, integrations, and maintainable codebases.

I enjoy working where **backend engineering, AI, automation, and enterprise software** meet — especially when a problem requires more than simply writing code and instead demands understanding the system, its constraints, its data, and how its components interact.

My interests include:

- 🐍 Backend engineering with Python
- ⚙️ REST APIs and service integration
- 🏢 Odoo 19 and ERP engineering
- 🤖 AI/ML application development
- 🧠 Large Language Models (LLMs)
- 🔎 Retrieval-Augmented Generation (RAG)
- 💬 Natural Language Processing (NLP)
- ⚡ Workflow and AI automation
- 🗄️ Relational and NoSQL databases
- 🧩 System integration and debugging
- 🚀 Scalable, modular, maintainable software

## 🧠 ReMIND — Multimodal AI Memory Reconstruction

<div align="center">

<a href="https://github.com/Hassan0086/ReMIND-Project">
  <img src="https://img.shields.io/badge/VIEW%20REPOSITORY-181717?style=for-the-badge&logo=github&logoColor=white" alt="Open ReMIND repository" />
</a>

</div>

**ReMIND** is a multimodal, agentic AI-based memory reconstruction system developed as a Final Year Project at the **University of Central Punjab**.

The system brings together conversational intelligence, image processing, voice processing, retrieval, and backend orchestration to generate context-aware memory reconstruction experiences.

### Architecture at a glance

```text
                     ┌───────────────────────┐
                     │      React Client     │
                     └───────────┬───────────┘
                                 │
                                 ▼
                     ┌───────────────────────┐
                     │     FastAPI Backend    │
                     └───────────┬───────────┘
                                 │
             ┌───────────────────┼───────────────────┐
             │                   │                   │
             ▼                   ▼                   ▼
       ┌────────────┐      ┌────────────┐      ┌────────────┐
       │   Text AI  │      │  Voice AI  │      │  Image AI  │
       └──────┬─────┘      └──────┬─────┘      └─────┬──────┘
              │                   │                  │
              ▼                   ▼                  ▼
          LLM / RAG          Speech / TTS       Vision / OCR
              │                   │                  │
              └───────────────────┼──────────────────┘
                                  ▼
                       ┌────────────────────┐
                       │     PostgreSQL     │
                       └────────────────────┘
                                  │
                                  ▼
                       ┌────────────────────┐
                       │     Cloudinary      │
                       └────────────────────┘
```

`Cloudinary`
